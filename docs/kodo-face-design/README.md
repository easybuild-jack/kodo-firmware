# Kodo（小睿同学）· 屏幕表情设计：方案 A「豆豆眼」（定稿）

> 给固件开发用。画布 **320×240 横屏**（ST7789 2.0 寸），深色背景。
> 实现：`main/boards/bread-compact-wifi-s3cam/kodo_face_display.{h,cc}`（类 `KodoFaceDisplay`）。
> 四选一设计页（本方案为其中的「方案 A：豆豆眼」）：https://cursor.com/canvas/store-0b5ae99c-d666-4f70-8822-1d961e5c49b9/207d1109-d96c-4518-a5bb-91802c1e5fa1
>
> 旧的「蓝线萌系机器人脸」（天线、侧耳、腮红、下巴灯，14 种表情）已被本方案取代，
> 它的 README 和 SVG 可以在 git 历史中找到（提交 `96673ee` 及更早）。

## 设计一句话

整张脸只有两块圆角矩形眼睛，类似 EMO、Cozmo。没有嘴、腮红、天线、耳朵和下巴灯，
全靠眼睛变高、变扁、弯成弧线、切掉一角来表达情绪。

## 色板

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | `#0B0F14` | 整屏底色，也是「难过」时切角三角形的颜色 |
| 眼睛 | `#4FD1FF` | 眼睛、开心弧线、思考圆点、睡觉 Z 字 |
| 辅助 | `#1B4A5C` | 设计稿备用色，固件目前未使用 |
| 状态栏 / 字幕文字 | `#CDEFFF` | 固件选用的浅色文字，保证在深色背景上可读 |

## 坐标约定

- 左眼中心 x = 100，右眼中心 x = 220（惊讶时为 96 / 224）。
- 圆角矩形的圆角半径 = `min(min(w, h) / 2, 24)`；惊讶时上限放宽到 44，眼睛变成正圆。
- 下表的 `cx, cy` 是中心点，`w × h` 是宽高，单位为像素。

## 8 种状态

`faces/` 目录下有每个状态的 SVG 参考图（320×240），由下表参数直接生成，可当视觉稿，不需要烧录。

| id | 中文 | 眼睛 | 附加元素 | 动画 |
|----|------|------|----------|------|
| `idle` | 待机 | 两眼 (100,120) / (220,120)，64×84 | 无 | 眨眼 |
| `happy` | 开心 | 两段粗弧线代替眼睛：`M(cx-32,136) Q(cx,70) (cx+32,136)`，线宽 20，圆头 | 无 | 无 |
| `listen` | 聆听 | 左眼 (100,114) 66×92，右眼 (220,112) 72×100，右眼略大，像歪头 | 无 | 眨眼 |
| `speak` | 说话 | 两眼 (100,120) / (220,120)，宽 66，高度在 58–84 之间起伏 | 无 | 说话起伏 |
| `think` | 思考 | 两眼 (118,104) / (238,104)，60×70，整体偏向右上 | 右上三个圆点：(276,60) r4、(288,46) r5、(302,30) r6，不透明度 60% | 眨眼 |
| `surprise` | 惊讶 | 两个正圆，(96,116) / (224,116)，r=44 | 无 | 无 |
| `sleep` | 困 / 睡觉 | 两条扁条，(100,134) / (220,134)，70×10 | 两个 Z 字：起点 (250,70) 边长 16、起点 (276,44) 边长 22 | 无 |
| `sad` | 难过 / 抱歉 | 两眼 (100,128) / (220,128)，64×70 | 背景色三角形切掉眼睛外上角：左 (60,88)(140,88)(60,130)，右 (180,88)(260,88)(260,130) | 无 |

## 动画

| 动画 | 参数 | 实现 |
|------|------|------|
| 状态切换 | 约 220 ms，ease-in-out | `lv_anim` 把眼睛的中心、宽高、圆角上限从「当前画面」插值到目标状态。弧线、圆点、Z 字、切角三角形随进度淡入淡出；切到「开心」时眼睛压扁并淡出，同时弧线淡入 |
| 眨眼 | 高度 → 8 → 原高度，共 150 ms；间隔 3.4–4.6 s 随机，平均约 4 s | 只在待机、聆听、思考三种状态下进行，用 `lv_anim` 实现 |
| 说话 | 眼睛高度 `84 - 26 × |sin(0.9 × t)|`，t 以 110 ms 为一帧，起伏周期约 0.38 s | 40 ms 的 `lv_timer` 刷新。设计稿说法是「随音量起伏」，固件目前拿不到 TTS 音量，所以按设计页预览用的正弦节奏实现 |

## 情绪字符串映射

服务器 `llm` 消息里的 `emotion` 字段，以及固件内部调用的 `SetEmotion()`，按下表映射。
未列出的字符串（例如 `warning`、`cancel`、`link`、`download`、`gear`）不改变表情，与旧实现一致。

| 状态 | 情绪字符串 |
|------|-----------|
| `idle` | `idle` |
| `happy` | `happy`、`laughing`、`funny`、`cool`、`confident`、`relaxed`、`delicious`、`silly`、`wink`、`winking`、`love`、`loving`、`kissy`、`shy` |
| `listen` | `listen`、`listening`、`look` |
| `speak` | `speak`、`speaking` |
| `think` | `think`、`thinking`、`confuse`、`confused` |
| `surprise` | `surprise`、`surprised`、`shocked` |
| `sleep` | `sleep`、`sleepy` |
| `sad` | `sad`、`crying`、`embarrassed`、`oops`、`angry` |
| 回到当前设备状态对应的表情 | `neutral`、`robot_2`（睡眠中则保持 `sleep`） |

## 设备状态驱动

由 `SetStatus()` 的状态文字驱动，逻辑与旧实现相同：

| 状态文字 | 表情 |
|----------|------|
| 待机（`STANDBY`） | `idle`；屏幕处于睡眠时保持 `sleep` |
| 聆听中（`LISTENING`） | 从待机 / 睡眠进入时，先 `surprise` 约 0.8 s（唤醒确认），再 `listen` |
| 说话中（`SPEAKING`） | `speak` |
| 连接中（`CONNECTING`） | `surprise`（从待机进入时同样走唤醒确认） |
| 错误（`ERROR`） | `sad` |
| 进入省电（`SetPowerSaveMode(true)`） | `sleep`，背光调到 20 |
| 退出省电 | `idle`，恢复背光 |

## 图层与性能

- 表情画在一个 320×240 的 `canvas_` 上，状态栏（`top_bar_` / `status_bar_`）、字幕栏（`bottom_bar_`）、拍照预览和低电量弹窗始终移到最上层，不会被表情挡住。
  所有状态的眼睛都在 y = 62–163 之间，不与顶部状态栏和底部字幕重叠；思考圆点最高到 y = 24，状态栏文字会画在它上面。
- 全部用 LVGL 原生对象：2 个圆角矩形 `lv_obj`、2 条 `lv_line`（开心弧线）、3 个圆形 `lv_obj`（思考圆点）、2 条 `lv_line`（Z 字），
  以及 `canvas_` 的 `LV_EVENT_DRAW_POST` 里用 `lv_draw_triangle` 画的两块切角三角形。没有位图资源。
- 对象只在初始化时创建一次，切换状态不再销毁和重建；每帧只在几何或不透明度真的变化时才修改样式，只重绘变化的区域。
  静止状态（惊讶、开心、难过、睡觉）不产生任何重绘。
