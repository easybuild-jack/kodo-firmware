# Kodo（小睿同学）· 屏幕表情设计（定稿）

> 给本地 Cursor / 固件开发用。画布 **320×240 横屏**，主色蓝线萌系机器人。
> 在线预览页：https://cursor.com/canvas/store-0b5ae99c-d666-4f70-8822-1d961e5c49b9/dd280331-9eda-461f-9b80-90caaf9d755d

## 设计一句话

蓝线勾边 + 大圆眼粉腮红：先可爱，再用天线、胶囊侧耳、下巴小灯提示「我是机器人」。

## 固定底板（所有表情共用）

相对 320×240：

1. **天线**：竖线 `(160,28)-(160,46)`，球心 `(160,22)` r=8，球上小高光
2. **侧耳胶囊**：左 `rect(30,90,26,52,rx=13)`，右 `rect(264,90,26,52,rx=13)`，各一颗装饰圆点
3. **脸板**：`rect(60,50,200,152,rx=36)`，描边 3px `#4C8DFF`
4. **下巴灯**：`(148,186)` `(160,186)` `(172,186)` 各 r=3
5. **淡铆钉**：`(76,66)` `(244,66)`

换表情时：**只改眼睛、嘴巴、装饰**，底板不动。

## 表情枚举（id）

| id | 中文 | 触发场景 | 眼睛 | 嘴巴 | 装饰 | 动效 |
|----|------|----------|------|------|------|------|
| idle | 平静 | 待机、等唤醒 | 大圆眼居中 | 小弧微笑 | 淡腮红 | 眨眼 4–6s 一次 |
| listen | 倾听 | listening | 略放大 | 微张 | 侧耳音波 | 音波交替闪 400ms |
| speak | 说话 | TTS | 圆眼或微弯 | 圆开口变大 | 下巴灯闪 | 嘴跟音量 8–12 帧 |
| think | 思考 | 等 LLM | 瞳孔右上 | 短横/猫嘴 | 三圆点 | 点依次亮 300ms |
| happy | 开心 | 问候/完成 | ^ ^ 弯月 | 大弧笑 | 腮红加深 | 上下弹 2 下 |
| wink | 眨眼 | 打招呼 | 左弯右线 | 歪嘴笑 | 右颊星 | 停 600–800ms |
| surprise | 惊讶 | 唤醒/打断 | 超大眼小瞳 | 小圆 O | 天线闪 | 放大 8% 弹回 |
| confuse | 疑惑 | 没听清 | 一大一小 | 波浪线 | 问号 | 左右摇 2 次 |
| sad | 难过 | ASR 失败 | 下垂 | 倒弧 | 圆泪 | 泪落一次 |
| sleep | 睡觉 | 长空闲 | 弯闭眼 | 小 n | Zzz | 呼吸缩放 2% |
| look | 观察 | 拍照问答 | 大眼盯前 | 抿嘴 | 取景角标 | 框闪一下 |
| love | 爱心 | 被夸 | 心形眼 | 大弧笑 | 两侧心 | 心上飘 1s |
| shy | 害羞 | 被夸英文 | 弯眼偏侧 | 猫嘴 | 大红晕 | 左右躲 |
| oops | 出错 | 网络/异常 | X X | 小波浪 | 感叹号 | 轻震 3 下 |

## 落地优先级

1. 底板一层（天线+侧耳+脸+下巴灯）
2. 先做静态：`idle` / `listen` / `speak` / `think` / `happy` / `sad`
3. 再做：`surprise` / `look` / `oops` / `sleep` / 其余
4. 三个循环动效：idle 眨眼、listen 音波、speak 嘴型
5. 状态机：`listening→listen`，`speaking→speak`，思考→`think`，唤醒→`surprise`→`happy`，错误→`oops`/`sad`，拍照→`look`

## 给 Cursor 的实现提示

- 表情名用上表 **id** 做枚举，不要用中文文件名当唯一标识。
- 优先矢量/几何图元（圆、椭圆、圆角矩形、弧线），少用大位图，省 Flash。
- 描边统一蓝色；腮红与爱心可用粉色填充。
- 同目录 `faces/` 下有各表情 SVG 参考（320×240），可当视觉稿，不必直接当资源烧录。
